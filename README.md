# Book University

Offline, private PDF reader for Windows, Android and Linux. C# .NET with Avalonia UI. No accounts, no tracking, no Google services. Installed only through GitHub Releases.

Planned core features: page view, scrolling, zoom with zoom lock, search, bookmarks, night mode, text selection.

Status: v0.1.0 (build 1) is a desktop shell only. PDF rendering comes next.
