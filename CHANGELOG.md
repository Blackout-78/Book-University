# Book University version history

Offline, private PDF reader for Windows, Linux and Android.

## v0.6.0 (build 6)
- Android app: library, reader, zoom lock, search, bookmarks, Night mode.
- Progress bars in the Android library and reader.
- Signed APK built by GitHub Actions and published on GitHub Releases.

## v0.5.0 (build 5)
- Type a zoom number (25 to 400).

## v0.4.0 (build 4)
- Library: add many PDFs at once (files, a whole folder, drag and drop).
- Remembers the last page read for each PDF.
- Remove a PDF from the library without touching the original file.

## v0.3.0 (build 3)
- Search with a results list.
- Bookmarks, saved on this computer.
- Windows and Linux builds published as downloads.

## v0.2.0 (build 2)
- Open a PDF and draw its pages.
- Page turns, zoom, and zoom lock.

## v0.1.0 (build 1)
- Desktop shell in Night style.
- Zoom and Night toggles.
- Version and build stamp.
